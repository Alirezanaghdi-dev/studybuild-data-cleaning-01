# studybuild-data-cleaning-01
Project 01: Data Cleaning on a Real E-commerce Dataset
دیتاست اولیه شامل ۶۱ ردیف و ۱۷ ستون بود. بعد از تمیزکاری، به **۵۶ ردیف** رسید.

---

## ۱. حذف ردیف با مقدار خالی در ستون `age`

**مشکل:** یک ردیف مقدار سن نداشت (NaN).

**تصمیم:** چون فقط یک ردیف بود و تاثیر آماری قابل‌توجهی نداشت، این ردیف کامل حذف شد (به‌جای حذف کل ستون، چون سن برای تحلیل مهمه).

```python
df = df.dropna(subset=['age'])
```

---

## ۲. حذف outlier در ستون `age`

**مشکل:** یک ردیف سن ۱۴۵ داشت که از نظر منطقی/بیولوژیکی غیرممکنه.

**تصمیم:** ردیف حذف شد چون مقدار نامعتبر بود و نمی‌شد به سن واقعی مشتری پی برد.

```python
df = df.drop(df[df['age'] == 145].index)
```

---

## ۳. حذف `customer_id` تکراری

**مشکل:** مقدار `customer_id = 1014` دو بار ثبت شده بود.

**تصمیم:** با `drop_duplicates` فقط اولین رخداد نگه داشته شد و بقیه حذف شدن.

```python
df = df.drop_duplicates(subset=['customer_id'])
```

---

## ۴. اصلاح ستون `gender` بر اساس `first_name`

**مشکل:** ستون `gender` ناسازگاری زیادی داشت — تقریباً هر اسم هم با مقدار M و هم F ثبت شده بود، که نشون می‌داد این ستون از ابتدا غیرقابل‌اعتماد بوده (نه چند خطای تصادفی، بلکه یک مشکل سیستماتیک).

**تصمیم:** چون جنسیت برای تحلیل مهم بود، به‌جای نادیده گرفتن این ستون، جنسیت هر مشتری بر اساس اسم رایج فارسی/انگلیسی‌اش دوباره تعیین شد.

```python
gender_map = {
    'Ali': 'M', 'Amir': 'M', 'Arash': 'M', 'Kimia': 'F',
    'Maryam': 'F', 'Mina': 'F', 'Neda': 'F', 'Parsa': 'M',
    'Reza': 'M', 'Sara': 'F', 'Sina': 'M', 'Zahra': 'F'
}

df['gender'] = df['first_name'].map(gender_map)
```

---

## ۵. اصلاح `avg_order_value` برای مشتری بدون خرید (`customer_id = 1024`)

**مشکل:** این مشتری `purchase_count = 0` داشت (یعنی هیچ خریدی نکرده)، اما `avg_order_value` مقدار غیرصفر (۶۳.۶۷) داشت — که از نظر منطقی درست نیست، چون بدون سفارش نمی‌شه میانگین ارزش سفارش داشت.

**تصمیم:** مقدار `avg_order_value` این ردیف به صفر تغییر کرد تا با `purchase_count = 0` و `total_spending = 0` هم‌خونی داشته باشه.

```python
df.loc[df['customer_id'] == 1024, 'avg_order_value'] = 0
```

---

## ۶. تبدیل `signup_date` به فرمت تاریخ (datetime)

**مشکل:** ستون `signup_date` به‌صورت رشته متنی (string) ذخیره شده بود، نه تاریخ واقعی.

**تصمیم:** تبدیل به datetime تا بشه محاسباتی مثل طول عضویت یا فیلتر بر اساس بازه‌ی زمانی روش انجام داد.

```python
df['signup_date'] = pd.to_datetime(df['signup_date'])
```

---

## ۷. حذف ردیف با `total_spending` ناسازگار (`customer_id = 1030`)

**مشکل:** برای این مشتری، حاصل‌ضرب `purchase_count × avg_order_value` باید تقریباً برابر `total_spending` باشه:

```
26 × 156.89 = 4079.14
```

اما مقدار ثبت‌شده‌ی `total_spending` برابر ۲۵۰۰۰ بود — حدود ۶ برابر بیشتر از چیزی که منطقاً باید می‌بود.

**تصمیم:** چون معلوم نبود کدوم مقدار (purchase_count، avg_order_value، یا total_spending) اشتباه ثبت شده، و فقط یک ردیف بود، کل ردیف به‌دلیل ناسازگاری داده حذف شد.

```python
df = df.drop(df[df['customer_id'] == 1030].index)
```

---

## ۸. حذف ردیف با مقدار خالی در ستون `total_spending`

**مشکل:** یک ردیف دیگه هم مقدار خالی (NaN) در ستون `total_spending` داشت.

**تصمیم:** برای یکدست ماندن با تصمیم مشابه در مرحله‌ی ۱ (age)، این ردیف هم حذف شد.

```python
df = df.dropna(subset=['total_spending'])
```
