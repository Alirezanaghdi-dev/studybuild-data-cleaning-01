# Sales Data Cleaning & Analysis Project


## Project Overview

This project focuses on cleaning, preprocessing and analyzing a sales dataset using Python.

The goal is to identify data quality issues, clean the dataset and prepare it for analysis.


## Dataset

The dataset contains customer sales information including:

- Customer information
- Purchase history
- Spending behavior
- Payment methods
- Customer satisfaction


## Data Cleaning Steps

The following steps were performed:

1. Data loading and understanding
2. Missing values analysis
3. Duplicate detection and removal
4. Text standardization
5. Data type validation
6. Outlier detection using IQR method
7. Final data validation


## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- OpenPyXL


## Final Dataset

After cleaning:

- Rows: 60
- Columns: 17
- Missing values: 0
- Duplicate rows: 0
